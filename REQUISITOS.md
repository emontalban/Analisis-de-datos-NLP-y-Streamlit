## 1. El reto: construir una solución con IA

Durante el curso hemos aprendido a programar con Python, trabajar con datos, realizar análisis exploratorios, crear visualizaciones, utilizar Machine Learning y desarrollar aplicaciones con ayuda de herramientas de Inteligencia Artificial.

El objetivo del proyecto final es **elegir un problema real, investigar los datos disponibles y construir una solución tecnológica que aporte valor a las personas o a la sociedad**.

No se trata solamente de entrenar un modelo o crear una aplicación atractiva: hay que recorrer todo el proceso:

**Problema → Datos → Análisis → Inteligencia Artificial → Aplicación → Resultados**

Al finalizar, cada equipo presentará su proyecto al resto de la clase durante una **Demo Day**.

## 3. Proyecto elegido: BUTACA-EMOCIONAL

### Proyecto 6 — Analizador de sentimientos y emociones en comentarios

### El problema

Las empresas y organizaciones reciben muchos comentarios y opiniones, pero analizarlos manualmente puede resultar complicado.

### Nuestro reto

Crear una aplicación que analice opiniones escritas por usuarios y **clasifique su sentimiento**.

### Requisitos específicos

- [x] Buscar un dataset de opiniones o reseñas etiquetadas.
- [x] Analizar los textos y sus categorías.
- [x] Preparar y limpiar los datos.
- [x] Utilizar **CountVectorizer** para transformar el texto en datos numéricos.
- [x] Entrenar un clasificador con **Scikit-learn**.
- [x] Evaluar los resultados y analizar los errores.
- [x] Crear una aplicación donde el usuario pueda introducir un comentario y obtener su sentimiento estimado.

### Funcionalidad mínima obligatoria

La aplicación debe permitir:

1. Introducir una opinión o comentario de texto.
2. Analizarlo mediante el modelo entrenado.
3. Mostrar el sentimiento estimado: **positivo**, **negativo**



### Reto extra (opcional)

- [ ] Analizar un conjunto de opiniones.
- [ ] Mostrar qué temas generan más comentarios positivos o negativos.
